# Xcent API Lab

## Project Overview
Xcent API Lab is a Python-based API monitoring and data quality platform designed to check external API availability, measure response times, validate response data, and track failures.

## Problem Statement
External APIs can become unavailable, return errors, respond slowly, or provide unexpected data. This project aims to identify and report these issues systematically.

## Planned Tech Stack
- Python
- FastAPI
- HTTPX
- pytest
- SQLite
- Git and GitHub Actions

## Core Features
- Register and manage API endpoints.
- Execute API health checks.
- Track HTTP status codes and response latency.
- Validate JSON responses.
- Record failures and check history.
- Expose REST endpoints for monitoring results.
- Automate tests and deploy a working demo.

## Testing Strategy
Test successful responses, timeouts, server errors, invalid JSON, malformed requests, and unexpected response data.

## Development Roadmap
1. Project setup and Python environment.
2. FastAPI application and REST endpoints.
3. External API monitoring.
4. Response validation and persistence.
5. Automated testing.
6. Deployment and CI.
7. Documentation and demo.
